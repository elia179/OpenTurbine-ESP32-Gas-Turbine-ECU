# Broader software review — local 2.5.6

The follow-up review covered calibration command lifecycles, settings-save paths, log downloads/previews and maintenance responses. Concrete fixes in this pass are browser-side:

- Fuel-pump minimum calibration's asynchronous three-cycle restart loop did not cancel when its Stop button was pressed. The manual slider refresh could also run during an intended off interval. A generation token cancels remaining work, including after a delayed acknowledgement; restart tests pause the sweep/refresh workers, and failure is shown without an unhandled promise rejection.
- Stop waits for its acknowledgement before showing Stopped. A failed stop remains visible and leaves the Stop control available. Saving the minimum first stops the manual refresh/output, awaits acknowledgement, then writes the value and preserves the Saved message.
- Oil calibration's three-second pump-off capture could run after cancellation. Its generation token now guards delayed captures and subsequent wizard transitions.
- STOP input changes and engine-mode transitions cancel active browser calibration workers. Returning to STANDBY or releasing STOP does not resume them. Cancellation here sends no actuator commands into a running engine; firmware mode/interlock logic remains authoritative.
- Calibration commands have a bounded response wait and require an explicit success acknowledgement. No calibration actuator command is automatically retried.
- Concurrent Log list refreshes and current-file reads could let an old empty/error response overwrite a newer success. Separate request generations guard list, current-file availability and selected chart preview. Current-file availability can still update while a past run remains selected. Malformed session lists now show an error rather than falsely reporting no files.

New source/gzip UI audits passed in Chromium, Firefox and WebKit. The calibration audit controls the actual wizard functions' waits/acknowledgements to verify cancel during a test, a delayed positive reply, all three normal on/off cycles, paused refresh, rejected stop, canceled oil delay and stop-before-save ordering. It also verifies cancellation on STOP/mode changes without emitting extra commands. The real command helper rejects malformed HTTP-200 acknowledgements. The Log audit reverses actual browser response order, checks stale empty/error replies, invalid-list recovery and simultaneous current availability/past-run preview.
