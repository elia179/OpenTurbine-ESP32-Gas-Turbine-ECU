# Wet-glow component tests — local 2.5.6 candidate

Tools retains the combined Wet Glow Test and adds an expandable component section: Glow only and Pilot-fuel pump / valve only. Heater-only suppresses the automatic pilot-fuel output for the whole test. Fuel-only starts the pilot-fuel output immediately, with the heater off. The configured Hardware heating On level/ramp and pilot-fuel command remain authoritative. Relay outputs use ON/OFF.

All three use the existing `tools.glow_test_ms` setting. Tools settings exposes one clearly labelled shared duration field, avoiding duplicate JSON keys. Saving updates every card's duration and description; reload retains it. The existing GLOW_TEST command carries a component selection in iParam (0 combined, 1 heater, 2 fuel), so all existing API/core output locks and single-test ownership apply. Invalid selections and pump-only without wet-fuel hardware are rejected at both entry layers. Timeout, STOP/all-off and standby entry reset the selection. Component overrides only apply in STANDBY/FAULT; engine sequences retain normal delayed wet-glow operation.

Related compound paths reviewed: Starter Test retains enable and delay qualification, with a separate Starter Enable Test already available. AB igniter, pump and valve already have separate tests. Extra Cooldown remains a combined operation whose component outputs already have individual tests. Registry mirrors intentionally follow their source and remain documented as coupled.

- New UI audit passed in Chromium, Firefox and WebKit, source and gzip pages: nested subcards, configured names and levels, real Run/confirmation payloads, mutual exclusion, running/STOP/cooldown locks, absent hardware and 800/400/320 px layouts. Screenshots inspected; subcard descriptions occupy a full row to remain readable on narrow screens.
- Actual Tool settings edit from 10 to 1.5 seconds saved, reloaded and appeared on all three cards, with one duration input.

This is local implementation and automated qualification. Component outputs have not been exercised on physical boards for this candidate; 2.5.5 remains the published release.

Repeated settings refresh also no longer duplicates fitted-output names.
