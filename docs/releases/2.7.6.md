# OpenTurbine 2.7.6

- Settings pages verify interrupted saves against the same ECU and retain drafts when the result is uncertain. Save messages distinguish storage confirmation, live application, and restart.
- Dashboard STOP stays available when live readings are stale. Connection, engine state, and common reasons START is unavailable are easier to see.
- Hardware, Calibration, Controllers, Sequence, Log, and System have clearer setup and recovery messages, with improved keyboard and narrow-screen behavior.
- Engine-file restore previews the saved engine and verifies the loaded setup after restart. The Windows Setup Tool checks that the engine setup matches its pre-update backup.

The recommended Windows package includes matching firmware and web files for Classic ESP32, ESP32-S3, and ESP32-S3 N8R2.
