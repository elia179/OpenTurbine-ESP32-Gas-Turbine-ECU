# OpenTurbine 2.7.1

Use **Setup Tool 0.8.0** and the matching recommended package. Back up the
complete engine file before updating. **Update and keep my setup** retains
configuration over Wi-Fi; **Clean install / reinstall** erases the selected
board over USB. Plain development boards need no PCB profile.

## Changes

- Add a separate **ESP32-S3 N8R2** image for modules with exactly **2 MB Quad
  PSRAM**. Session recording can use up to 1 MiB of that memory, with an internal
  RAM fallback. Larger PSRAM capacities are not used. More recording RAM does
  not increase permanent flash-log storage; recording capacity and dropped rows
  remain visible on Log.
- Setup Tool selects the N8R2 image for the current **OpenTurbine PCB v1.0**
  profile. Existing generic S3 and Classic targets remain available. Package
  schema 5 requires Setup Tool 0.8.0 or newer.
- Separate controller behavior from shutdown protection settings. Oil-circuit
  low-pressure and afterburner guards live under Shutdown & Protection;
  controller-specific feedback-loss fallback stays with its controller.
- Make controller unit changes consistent, distinguish temperature thresholds
  from temperature differences, and preserve exact untouched or reverted
  values during saves. Keep System file selections and progress when units
  change.
- Allow input/output draft cards before their hardware or shared buses are
  configured. Required connections must still be complete before saving.
  Thrust offers ADC, HX711, TLA2528 and NAU7802 interfaces, including guided
  HX711 calibration in newtons.
- Sequence NAU7802 conversion-byte reads explicitly and recover automatically
  after an ADC-only configuration reset without losing saved calibration.
- Release an interrupted firmware-update session after its idle timeout,
  including a lost connection between acknowledged chunks. Page access and a
  fresh update become available without restarting the ECU.

## PCB and verification scope

The only bundled official profile is **OpenTurbine PCB v1.0**, revision
**1.0-20261108**, targeting **ESP32-S3-WROOM-1-N8R2**. Use its matching firmware
and installer. Older routings remain archived. The separate PCB guided-build
walkthrough is not included in this release.

Classic and generic S3 passed unloaded-fixture update/recovery, logging and
browser checks; the S3 also exercised the PCB-profile interface. The actual
N8R2 module and assembled PCB were unavailable. Their PSRAM boot behavior,
electrical operation, current ratings and thermal margins remain unqualified.

NAU7802 emulation passed calibration sweeps, both polarities, byte/sign
boundaries and ADC-reset recovery on both chips. The reported physical
nonmonotonic load-cell curve was not reproduced, including with published
2.6.0 firmware. The byte-ordering change is not a confirmed explanation of
that report; the original sensor setup still needs verification.

The PCB connector-guide bullet indentation has a known cosmetic clipping
issue, deferred to the next version.
