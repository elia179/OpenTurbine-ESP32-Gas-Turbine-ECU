# OpenTurbine 2.7.0

Use **Setup Tool 0.7.9** and the matching recommended package. The release includes
Classic ESP32 and ESP32-S3 firmware, web pages, the Windows tool, and the
OpenTurbine PCB v1.0 profile. Each download has a SHA-256 sidecar.

Back up the complete engine file before updating. **Update and keep my setup**
uses Wi-Fi and retains configuration; **Clean install / reinstall** uses USB and
erases the selected board. Plain development boards need no PCB profile.

## Main changes

- MAVLink 2 replaces the old OpenTurbine Cluster protocol. It provides named
  telemetry, explicitly permitted engine commands and a controller throttle
  source with input-loss handling. Update the receiving application using the
  [Cluster example](https://github.com/elia179/OpenTurbine-ESP32-Gas-Turbine-ECU/blob/v2.7.0/examples/cluster/README.md) or
  [MAVLink/ArduPilot integration guide](https://github.com/elia179/OpenTurbine-ESP32-Gas-Turbine-ECU/blob/v2.7.0/examples/mavlink/README.md).
  Review sender permissions and controller input-loss settings before use.
- The Setup Tool asks for the initial Wi-Fi connection, verifies reconnection
  after updates, shows final-verification progress, and offers verification-only
  retry. USB setup identifies the board and makes erase/write stages explicit.
- Hardware configuration offers named PCB connectors and compatible signal
  types, external sensor choices, exposed GPIOs and advanced wiring details.
  Missing onboard devices stay visibly unavailable; saved assignments and
  complete engine-file restores retain the PCB wiring. HX711 is identified as
  digital DOUT/SCK.
- Large engine backups use temporary restore memory, and large dashboard snapshots
  stream without truncation. Large browser replies share a bounded transfer
  budget. S3 snapshots reuse the idle transmit workspace and release the JSON
  tree before transmission; only serialized bytes remain in flight. Persistent PCB faults create one notification per
  fault episode instead of flooding the log during shutdown.
- A separate optional Fault LED takes over fault indication when fitted. The
  Status LED retains fault indication when no separate fault indicator is used.
- Compound sequencer steps show their output commands. System sections open on
  entry; short-screen search/save controls hide and reveal smoothly. Navigation
  shows a loading state while the next page and telemetry become ready.
- Browser update/save timeouts remain active until the acknowledgement body
  finishes, including interrupted responses and CSV downloads.
- Configuration pages recover from temporary contention using the ECU's retry
  delay, with a bounded wait and a visible error if loading cannot complete.
- Selected session data uses compact bounded storage. Log settings estimate
  recording duration; loop-timing diagnostics default off for new setups.
  Existing saved choices are retained. Event reads and downloads handle memory
  pressure without losing the most recent fault/shutdown tail.

## OpenTurbine PCB v1.0

This is the **only supported official PCB routing**. It requires
**ESP32-S3-WROOM-1-N8, 8 MB flash, no PSRAM**, and its matching profile. Older
routings are archived and excluded from the installer. The profile is bundled;
the standalone `OpenTurbine_PCB_v1.0.otpcb.json` download is the same routing.

Start/Stop and indicator connections are configurable defaults. ADC, IN, OUT,
PWM and thermocouple connectors retain their electrical restrictions. See the
[board wiring and recovery notes](https://github.com/elia179/OpenTurbine-ESP32-Gas-Turbine-ECU/blob/v2.7.0/pcb_profiles/official/openturbine-s3-20261102.md)
and **Hardware → board summary → Connector guide & electrical limits**.

PCB support remains prototype support. Bare-board fixture checks do not
establish assembled-board current ratings, switching/thermal margins or
live-engine safety. The actual PCB still needs electrical qualification.

## Windows availability

The tool is signed when the project's signing certificate is configured.
Unsigned builds may be blocked by Smart App Control or an organization signing
policy. Do not disable Windows security for OpenTurbine; see the
[installation guide](https://github.com/elia179/OpenTurbine-ESP32-Gas-Turbine-ECU/blob/v2.7.0/docs/USER_GUIDE.md#if-windows-blocks-the-installer).
