# OpenTurbine 2.7.3

Physical analog measurements now continue beyond saved calibration points. A pressure sensor calibrated up to 3.6 bar can report a higher pressure when its electrical signal remains valid. Nonlinear tables still use each segment's slope between points and continue the nearest segment beyond either end. Legacy polynomial calibrations retain their in-range fit and use straight-line extensions outside it.

Calibration shows the saved input range for point tables on supported cards. The Dashboard marks readings outside the calibrated range as estimates when it can identify the source. Check those readings against a known reference before relying on their accuracy. Throttle and other normalized inputs retain their endpoint command limits.

Use Setup Tool 0.8.0 or newer with the matching firmware and web package. Classic ESP32, generic ESP32-S3 and S3 N8R2 remain supported targets. The OpenTurbine PCB v1.0 profile and the engine configuration file format carry forward.
