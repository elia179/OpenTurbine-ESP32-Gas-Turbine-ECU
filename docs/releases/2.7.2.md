# OpenTurbine 2.7.2

Use Setup Tool 0.8.0 or newer with the matching package. Update firmware and web
files together. Back up the complete engine file before updating; the normal
Wi-Fi update retains the setup.

## Changes

- Appearance can keep search/save controls compact until you press Show
  controls. Hide controls compacts them again. The browser remembers the choice
  across settings pages. Closed cards show warning counts without reopening
  during unrelated edits.
- Oil-target warnings use the active pump controller and its own enabled
  low-pressure protection. Dormant legacy values, disabled controllers and
  removed startup steps do not activate their old pressure checks.
- Warning links reveal the relevant fields and cards, including named oil
  circuits, startup steps and PCB diagnostics. Same-page links retain draft
  edits; leaving the page retains the unsaved-change confirmation.
- Temperature comparisons agree between inline/save warnings and Celsius or
  Fahrenheit. Disabled temperature protection no longer causes misleading
  comparisons, and a zero disabled bar limit does not fail the margin check.
- Unavailable oil-controller definitions can be removed; recreating controllers
  does not reuse an occupied ID. General oil-switch protection is distinguished
  from each named pump's pressure protection.
- Correct the PCB connector-guide bullet indentation and update oil-setting
  paths and controls guidance.

## Compatibility and verification scope

Classic ESP32, generic ESP32-S3 and S3 N8R2 images remain available. The bundled
PCB profile remains OpenTurbine PCB v1.0, revision 1.0-20261108. Development boards
still work without a PCB profile. The PCB guided-build walkthrough remains
unpublished.

The physical N8R2 module and assembled PCB are not available for this bench.
Their electrical operation and exact-module PSRAM boot qualification remain
separate from the development-board/profile checks.
